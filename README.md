# 班级随手记

一个面向班主任的本地优先班级工作手账。无需账号、无需后端，可安装到手机桌面，首次加载后离线使用。

## 可以做什么

- 快速记录请假、表扬、冲突、活动和其他班级事项
- 一条记录可选择多名学生，也可以记录到“全班”
- 建立学生名单，记录组别、家长联系方式和备注
- 按学生、关键词、事项类型回看历史记录
- 标记“需要后续跟进”，集中处理未完成事项
- 按学生查看个人记录、表扬次数和待跟进项
- 导出完整 JSON 备份、Excel 可读的 CSV 表格，并支持恢复备份
- 适配 iPhone 和 Android 手机尺寸，也可在电脑浏览器使用

## 本地预览

在项目目录运行：

```bash
python3 -m http.server 4173
```

浏览器打开 `http://127.0.0.1:4173/`。首次进入会显示班级设置页；访问 `http://127.0.0.1:4173/?demo=1` 可以打开纯示例数据。

## 放到手机使用

PWA 需要通过 HTTPS 打开一次，浏览器才能缓存应用并安装到桌面。

1. 将本目录中的 `index.html`、`styles.css`、`app.js`、`sw.js`、`manifest.webmanifest` 和 `icons/` 一起上传到任意静态网站托管服务。
2. 在手机上打开获得的 HTTPS 链接。
3. iPhone 使用 Safari：点击“分享” → “添加到主屏幕”。
4. Android 使用 Chrome：打开菜单 → “安装应用”或“添加到主屏幕”。
5. 安装完成后，从桌面图标打开；之后即使断网也能记录和查看。

首次加载必须联网。应用更新后重新打开一次，新的离线缓存会在后台准备。
请在 Safari 或 Chrome 中完成安装，微信内置浏览器通常不支持添加到桌面。

## 单文件版

`班级随手记-单文件版.html` 把样式、脚本和图标都放在一个文件里，方便直接传到手机或电脑上打开。

单文件版不包含 Service Worker 缓存和安装能力，适合应急、本地预览或无法部署静态站点时使用。长期使用仍建议部署完整 PWA 版本。

## 数据与隐私

- 所有班级、学生和记录数据只保存在当前浏览器的本地存储中，不会上传到服务器。
- 备份文件由用户自己保存，其中包含真实学生信息，请勿随意转发。
- 清除浏览器数据、卸载 PWA、更换手机或系统清理应用数据之前，务必先导出 JSON 备份。
- 更换手机时：在旧手机导出完整备份，在新手机打开应用后从“设置与备份”恢复。
- 本应用没有云同步，也不提供跨设备实时同步。

## 文件结构

```text
index.html               页面骨架与图标
styles.css               响应式界面样式
app.js                   名单、记录、筛选、备份等逻辑
manifest.webmanifest     PWA 安装信息
sw.js                    离线缓存
icons/                   桌面图标
```
